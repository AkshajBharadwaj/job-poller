LESS CHECKING. MORE APPLYING.

New opportunities.
One inbox.

A personal tool that checks public company career pages and sends an email when it discovers a new matching internship.

Built for personal use by Akshaj Bharadwaj
01 / CHECK

Watch career pages

The poller periodically checks public job listings and applies each company’s role and location filters.

02 / COMPARE

Spot new postings

A local database tracks previously seen postings. The first run establishes a baseline for future alerts.

03 / NOTIFY

Send an email

New matching roles are sent to the configured recipient, with the job title, location, and application link.

About Gmail access

With the account owner’s authorization, this tool uses the Gmail API to send job alerts. It requests send-only permission; it does not request permission to read your inbox. This is a personal project, with no public registration.
