Privacy policy

Last updated September 16, 2026

Job Poller Alerts is a personal job-notification tool operated by Akshaj Bharadwaj. This policy explains the information used by the tool and this informational website.

Information the tool uses

The tool collects public job titles, locations, posting identifiers, and application links from company career pages. It stores previously seen postings in a database to identify new opportunities.

The email configuration contains the sender and recipient addresses, a Google OAuth client ID and client secret, and a refresh token. The refresh token allows the tool to obtain access tokens and send alerts when the account owner is offline.

Gmail permission and purpose

The tool requests only the Gmail API’s gmail.send permission to send job-alert emails from the authorized account to the configured recipient. It does not request inbox-reading, contact-reading, or email-deletion permissions. Email addresses and authorization credentials are used to deliver these alerts, not for advertising or profiling.

Storage and sharing

Configuration and job records are stored on the operator’s computer and/or the DigitalOcean server hosting the poller. Credential files are excluded from the source repository and restricted with filesystem permissions. Google processes authorization requests and sends the email; DigitalOcean hosts the running application and its stored configuration. Messages are delivered to the configured recipient and may remain in the sender’s and recipient’s mailboxes.

Google user data is not sold, used for advertising, or used to train AI models. Job Poller Alerts’ use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Job records and configuration are retained until the operator deletes them or retires the deployment. You can revoke the app’s access through Google Account connections. Revoking access stops the tool from obtaining new access tokens; it does not delete previously delivered email. Contact the operator to request removal of locally or server-stored credentials and configuration.

This website

This static website is hosted on GitHub Pages. It has no signup form, advertising, or application analytics. GitHub may process ordinary access logs such as IP addresses; see GitHub’s privacy statement. Fonts are requested from Google Fonts, which receives the network information needed to serve those requests.
